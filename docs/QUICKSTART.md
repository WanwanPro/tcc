# 🚀 快速启动指南

## 2.5D 停车场导航系统

本指南将帮助你快速启动和测试 TCC 停车场 2.5D 导航系统。

---

## ✅ 前置要求

- **Node.js** 14+ 
- **微信开发者工具** 
- **MongoDB** (用于后端系统，可选)

---

## 📦 步骤 1: 安装依赖

```bash
cd C:\Users\wanan\Desktop\Sync\tcc
npm install
```

---

## 🗺️ 步骤 2: 生成地图数据

运行以下命令将 `tcc1date1.json` 转换为导航系统所需的数据格式：

```bash
npm run gen-map-data
```

这会生成两个文件：
- `frontend/miniprogram/assets/map_elements.geojson` (168个停车位 + 地图元素)
- `frontend/miniprogram/assets/navigation_graph.json` (47个导航节点 + 54条边)

---

## 📱 步骤 4: 启动微信小程序

### 4.1 打开微信开发者工具

1. 启动**微信开发者工具**
2. 选择「导入项目」
3. 选择目录：`C:\Users\wanan\Desktop\Sync\tcc\frontend\miniprogram`
4. 填写 AppID（测试账号可选）

### 4.2 编译运行

1. 点击「编译」按钮
2. 在底部 Tab 栏选择「导航」页面
3. 地图会自动加载并渲染

---

## 🎮 步骤 5: 体验导航功能

### 5.1 移动车辆

- 拖动左下角的**虚拟摇杆**
- 摇杆偏移越大，车辆移动越快
- 释放摇杆自动停止

### 5.2 开始导航

1. 点击右下角「**开始导航**」按钮
2. 在弹出的列表中选择目的地：
   - 入口1
   - 出口
   - 电梯
   - B区车位
   - A区车位
3. 系统会自动规划路径并显示**蓝色引导线**

### 5.3 其他功能

- **停止导航**：点击「停止导航」按钮
- **重置视角**：点击「重置视角」恢复初始视角

## 🖥️ 步骤 6: 启动后端系统（可选）

如果需要测试完整的系统（含后端数据同步）：

```bash
# 启动所有服务（3个窗口统一）
start-all.bat

# 或分别启动
npm run start-tcc        # TCC后端 (3001)
npm run start-system     # System后端 (5000)
npm run start-frontend   # System前端 (5002)
```

访问：
- **TCC后端 API**: http://localhost:3001
- **System后端 API**: http://localhost:5000
- **System管理前端**: http://localhost:5002/login
  - 默认账号: `admin` / `admin123`

## 🐛 常见问题

### Q1: 地图不显示？

**解决方案**：
1. 检查控制台是否有错误
2. 确认数据文件已生成 (`npm run gen-map-data`)
3. 重新编译小程序

### Q2: 摇杆不响应？

**解决方案**：
1. 检查开发者工具是否开启了「真机调试」
2. 尝试在真机上测试（模拟器可能不支持 movable-view）

### Q3: 路径规划失败？

**解决方案**：
1. 运行测试脚本验证导航图：`node scripts/test-navigation-system.js`
2. 检查节点是否连通
3. 重新生成导航图：`npm run gen-navgraph`

### Q4: Canvas 渲染异常？

**解决方案**：
1. 确保使用的是 `type="2d"` Canvas
2. 检查 Canvas 是否正确初始化
3. 查看 `render-engine.js` 的错误日志
