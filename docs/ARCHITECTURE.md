## 各层详细说明

### 1. 表现层 (Presentation Layer)

#### 微信小程序
- **技术栈**: 微信小程序原生框架
- **功能模块**:
  - 2.5D地图渲染引擎
  - 实时导航功能
  - 用户交互界面
  - 车位查询与预约

#### 管理后台
- **技术栈**: Vue 3 + Vite + Element Plus
- **功能模块**:
  - 车位管理 (增删改查)
  - 数据分析统计
  - 系统配置管理
  - 用户权限管理

#### API接口
- **技术栈**: Node.js + Express
- **功能模块**:
  - RESTful API
  - WebSocket实时通信
  - 接口鉴权与限流

### 2. 业务层 (Business Layer)

#### 导航服务
| 功能 | 描述 |
|------|------|
| 路径计算 | 基于A*算法的最优路径规划 |
| 实时调整 | 动态避障与路径重规划 |
| 多目标优化 | 距离、时间、拥堵度综合优化 |

#### 车位分配服务
| 功能 | 描述 |
|------|------|
| 智能推荐 | 基于用户偏好的车位推荐 |
| 负载均衡 | 停车场区域负载均衡分配 |
| 预约管理 | 车位预约与释放管理 |

### 3. 服务层 (Service Layer)

#### 路径规划服务
```
┌────────────────────────────────────┐
│          A*算法引擎                │
│  ┌──────────────────────────────┐  │
│  │ 1. 初始化开放列表和关闭列表  │  │
│  │ 2. 计算F = G + H 代价       │  │
│  │ 3. 选择最小F值节点扩展      │  │
│  │ 4. 更新邻居节点代价         │  │
│  │ 5. 重复直到找到目标         │  │
│  └──────────────────────────────┘  │
│                                    │
│  权重计算:                         │
│  - 距离权重: 0.4                   │
│  - 拥堵权重: 0.3                   │
│  - 偏好权重: 0.3                   │
└────────────────────────────────────┘
```

#### 数据映射服务
- 模型转换: DTO ↔ Entity 转换
- 状态同步: 实时数据状态同步
- 数据验证: 输入数据校验

#### API适配服务
- 多源数据整合
- 缓存管理 (Redis)
- 请求聚合与分发

### 4. 数据层 (Data Layer)

#### MongoDB 数据模型

```javascript
// 车位表 (parking_spaces)
{
  _id: ObjectId,
  spaceId: String,           // 车位编号
  lotId: String,             // 停车场ID
  area: String,              // 区域
  floor: Number,             // 楼层
  status: String,            // 状态: available/occupied/reserved
  position: {                // 位置坐标
    x: Number,
    y: Number
  },
  features: {                // 车位特性
    nearEntrance: Boolean,
    nearElevator: Boolean,
    hasCharging: Boolean
  }
}

// 路径表 (navigation_paths)
{
  _id: ObjectId,
  startNode: ObjectId,       // 起点节点
  endNode: ObjectId,         // 终点节点
  pathNodes: [ObjectId],     // 路径节点序列
  distance: Number,          // 路径距离
  estimatedTime: Number      // 预计时间
}

// 地图节点表 (map_nodes)
{
  _id: ObjectId,
  nodeId: String,            // 节点编号
  type: String,              // 类型: entrance/exit/junction/space
  position: {                // 位置坐标
    x: Number,
    y: Number,
    z: Number
  },
  connections: [ObjectId]    // 连接的节点
}

// 用户偏好表 (user_preferences)
{
  _id: ObjectId,
  userId: ObjectId,          // 用户ID
  preferences: {
    preferNearEntrance: Boolean,
    preferNearElevator: Boolean,
    preferCharging: Boolean,
    maxWalkingDistance: Number
  }
}
```

## 技术选型

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| 前端 | Vue 3 + Vite + Element Plus | 管理后台 |
| 小程序 | 微信小程序原生 | 用户端 |
| 后端 | Node.js + Express | API服务 |
| 数据库 | MongoDB | 数据存储 |
| 缓存 | Redis | 数据缓存 |
| 容器 | Docker + Docker Compose | 部署容器化 |

## 数据流向

```
用户请求 → Nginx → API网关 → 业务服务 → 数据服务 → MongoDB
                ↓
              Redis缓存
```
