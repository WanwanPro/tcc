二、实体关系说明表

关系 类型 说明 所属数据库
Role → User 1:N 一个角色可分配给多个后台用户 parking_admin
ParkingLot → ParkingSpace 1:N 一个停车场包含多个停车位 parking_admin
ParkingLot → MapNode 1:N 一个停车场包含多个地图节点 parking_admin
ParkingLot → PricingRule 1:N 一个停车场可配置多条计费规则 parking_admin
ParkingLot → NavigationPath 1:N 一个停车场拥有多条导航路径 parking_admin
MapNode → NavigationPath 1:N 地图节点作为导航路径的起点或终点 parking_admin
MiniProgramUser → Vehicle 1:N 一个小程序用户可绑定多辆车 parking_admin
MiniProgramUser → ParkingRecord 1:N 一个用户可产生多条停车记录 parking_admin
Vehicle → ParkingRecord 1:N 一辆车可有多条停车记录 parking_admin
ParkingSpace → ParkingRecord 1:N 一个停车位可产生多条停车记录 parking_admin
Admin → Transaction 1:N 管理员可处理多条交易记录 parking_admin
PricingRule → Transaction 1:N 一条计费规则可应用于多条交易 parking_admin
Admin → Analytics 1:N 管理员可生成多份分析报表 parking_admin
User → OperationLog 1:N 一个用户可产生多条操作日志 parking_admin
ParkingSpace → ParkingSpaceLog 1:N 一个停车位可有多条操作日志 parking_admin
ParkingSpace → ParkingSpaceStatusHistory 1:N 一个停车位有多条状态变更历史 parking_admin
